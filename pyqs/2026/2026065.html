Question 65

65. An alloy P contains 20% copper and 80% zinc by weight. Another alloy Q contains 60% copper and 40% zinc by weight. A third alloy R is to be prepared from P and Q so that it contains equal amount of copper and zinc. In what ratio, amounts of P and Q be mixed in order to get R?

Select the answer using the code given below.

  • (a)1 : 3
  • (b)3 : 1
  • (c)2 : 3
  • (d)3 : 2
