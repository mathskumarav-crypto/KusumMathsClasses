Question 75

Match List-I with List-II.

List-I (Barrier to Communication)

A. Semantic
B. Cognitive
C. Organisational
D. Affective

List-II (Example)

1. Lack of feedback
2. Misunderstanding the meaning of a word
3. Fear of social stigma
4. Information overload

Select the answer using the code given below.

Code A B C D
(a) 3 1 4 2
(b) 3 4 1 2
(c) 2 1 4 3
(d) 2 4 1 3
  • (a) A-3, B-1, C-4, D-2
  • (b) A-3, B-4, C-1, D-2
  • (c) A-2, B-1, C-4, D-3
  • (d) A-2, B-4, C-1, D-3
